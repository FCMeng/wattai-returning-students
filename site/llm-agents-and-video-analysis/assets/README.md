# LLM Agents and Video Analysis assets

The SVG figures are original local course assets. They are referenced relatively by the notebooks and require no separate download.

`nasa_three_pacific_hurricanes.mp4` is a 44-second NASA Scientific Visualization Studio item showing Hurricanes Kilo, Ignacio, and Jimena in nighttime and daylight mosaics. `nasa_video.json` records its source, credit, usage guidance, checksum, and access date. `video_ground_truth.json` is a human-reviewed teaching reference for that clip.

The packaged NASA clip is the approved common input for live classroom comparisons. Students must record endpoint, exact model ID, prompt, and decoding settings with every result.
