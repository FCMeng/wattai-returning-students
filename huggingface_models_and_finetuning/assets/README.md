# Course assets

The PNG diagrams are course-original and embedded in the notebooks for reliable offline rendering. `nasa_three_pacific_hurricanes.mp4` is a real public-domain NASA Scientific Visualization Studio clip used by the optional video lab. Its source, license, checksum, and access date are recorded in `nasa_video.json` and `sources.json`.

External media is distributed only when its terms permit redistribution. The model examples may download weights from Hugging Face on first use; model cards are linked rather than copied.
